# FreshBite – Online Food Ordering

Frontend web development internship project for Data Alcott Systems.

## Project
FreshBite is a responsive food-ordering e-commerce demo focused on Hamirpur, Himachal Pradesh. It uses HTML5, CSS3 and vanilla JavaScript. No database or real payment gateway is used.

## Pages
Home, Restaurant Listing, Menu, Product Detail, Shopping Cart, Checkout, User Account, Login/Register, About Us and Contact Us.

## Features
- Restaurant categories and featured dishes
- Search and dietary filtering
- Add to cart
- Quantity adjustment and total calculation
- Simulated checkout and order ID
- Demo login/register
- Account and order history using localStorage
- Contact form
- Responsive mobile layout
- Hamirpur location section

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Create a **public** repository, upload all files, then open **Settings → Pages → Deploy from a branch → main → /(root) → Save**. GitHub Pages can host static HTML/CSS/JavaScript projects.
