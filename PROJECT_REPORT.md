# FreshBite – Online Food Ordering
## Internship Project Report

### 1. Objective
The objective of FreshBite is to develop a responsive online food-ordering website that demonstrates a realistic e-commerce journey. Users can browse restaurants, explore food items, view product information, add items to a cart, adjust quantities and complete a simulated checkout.

### 2. Technologies Used
- HTML5 – semantic structure and forms
- CSS3 – responsive layout and UI styling
- JavaScript (ES6) – cart, search/filtering, authentication and checkout interactions
- Browser localStorage – demo cart/account/order data
- Git & GitHub – source-code version control
- GitHub Pages – static website deployment

### 3. Main Features
Home page, restaurant listing, menu with dietary filtering, product detail, shopping cart, checkout, simulated login/register, user account, About Us and Contact Us pages, responsive mobile design, and Hamirpur location information.

### 4. Learning Outcomes
The project develops practical skills in semantic HTML, responsive CSS, JavaScript DOM manipulation, events, browser storage, form validation, UI design, GitHub repositories and static website deployment.

### 5. Challenges
The main challenges were maintaining a consistent design across pages, synchronizing cart state, making the interface responsive on small screens, and simulating checkout/authentication without a backend database. These were addressed with reusable CSS classes, JavaScript functions and localStorage.

### 6. Conclusion
FreshBite demonstrates a complete frontend food-ordering workflow from discovery to checkout. It is an internship demonstration and does not process real payments or store sensitive user information.
