# FreshBite – 3–5 Minute Demo Script

**0:00–0:20 Introduction:** Introduce FreshBite, the Data Alcott Systems web-development task, and the HTML/CSS/JavaScript stack.

**0:20–0:50 Home:** Show the hero banner, Hamirpur location, categories and featured dishes.

**0:50–1:25 Restaurants:** Open Restaurant Listing, explain cuisine, ratings, prices and delivery time, then demonstrate search.

**1:25–2:00 Menu + Product:** Search for pizza, use the Veg/Non-Veg filter, open Product Detail and explain description, dietary tag, price and Add to Cart.

**2:00–2:40 Cart:** Add 2–3 dishes, open Shopping Cart, demonstrate quantity +/−, remove, subtotal, delivery charge and total.

**2:40–3:20 Checkout:** Enter demo details and a Hamirpur address, select a simulated payment method, place the order and show the generated order ID.

**3:20–3:50 Account:** Demonstrate Login/Register and the Account page with simulated order history.

**3:50–4:20 Mobile:** Resize to mobile view and show responsive navigation, cards, menu and cart.

**4:20–4:40 Conclusion:** Explain that the project demonstrates a complete frontend food-ordering workflow with responsive design, filtering, cart management, simulated checkout and account features.
